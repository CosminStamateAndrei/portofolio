01Age 12 · Roblox

The baseplate

I started where a lot of people do: a grey Roblox baseplate and a tutorial playing on the side. I copied scripts I didn't understand, broke them, and slowly worked out why they did what they did.

Lua was the first language I ever wrote, even if back then I just called it "scripting".

Then I wanted to build things
people actually used.

02Discord bots

Where it clicked

A Discord bot is a real program with real users. It has to stay online, handle commands nobody planned for, and not fall over when a server gets busy.

That's when I stopped following tutorials line by line and started actually learning — and made the first applications I was proud of: a role manager, a slot machine, a crypto tracker, an event finder built on the Ticketmaster API.

commands→events→APIs→databases→users

03Exploring

Everything else

After that I got curious about all of it. Different languages, and the different kinds of things you can make with them — websites, tools, games, little scripts that save ten minutes a day.

Each one taught me something the others couldn't.

04University

Fundamentals

Now I study Computing Science at the University of Groningen. It takes years of figuring things out on my own and gives them a foundation: how things work underneath, why some solutions hold up and others don't, and how to build software with other people.

—Selected work

Things I've built

  1. EnderMaps ↗ A real-world map that renders like the in-game map from a certain blocky sandbox game: chunky pixel tiles, an F3-style debug HUD, /locate search. No image assets at all. React · Leaflet · OpenStreetMap
  2. memotime ↗ A shared, live Dutch ↔ English word list with translation practice. Forgiving answer checking that ignores accents and articles and flags small typos. React · Supabase · Vercel

  4. Event Locator ↗ A Discord bot that finds events near a city through the Ticketmaster API, filters out finished sales, and pages through results with buttons. Python · discord.py · REST
  5. Dutch RVD policies ↗ A dataset of responsible vulnerability disclosure policies from 90 Dutch companies, with a calibration set and prompts for LLM analysis. Python · Security research
