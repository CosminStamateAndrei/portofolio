01Roblox, age 12

The baseplate

My first attempts at programming were games in Roblox Studio, built by following YouTube tutorials. A lot of the time I copied scripts without fully understanding them, changed things until they broke, and then tried to figure out why.

Looking back, that was my first experience with Lua, and also with debugging.

After a while I wanted to build
things other people would use.

02Discord bots

Discord bots

Discord bots were where I started learning properly. A bot runs all the time, is used by real people in ways you did not anticipate, and has to keep working when a server gets busy.

This was when I stopped following tutorials step by step and began designing my own applications, among them a role manager, a crypto-currency tracker and an event finder built on the Ticketmaster API.

commands→events→APIs→databases→users

03Exploring

Other languages

From there I spent a lot of time trying out different languages and the kinds of software you can build with them: websites, small tools, games and scripts that automate repetitive tasks.

Working in several languages made it easier to tell which ideas belong to one specific language and which ones carry over to all of them.

04University

University

I completed my BSc in Computing Science at the University of Groningen. It gave me the theory I had been missing as a self-taught programmer, from algorithms and data structures to reasoning formally about programs.

I am now doing my MSc in Computing Science, specialising in Software Engineering and Distributed Systems. My interest is mainly in how large systems are designed so that they stay correct and maintainable when they run across many machines.

05Projects

Projects

  1. EnderMaps ↗ A web map of the real world, styled after the in-game map from Minecraft. It uses pixelated map tiles, shows a debug overlay with block and chunk coordinates, and supports searching for places through a chat-style /locate command. React, Vite, OpenStreetMap
  2. memotime ↗ A shared Dutch and English vocabulary list with translation practice in both directions. The answer checking ignores case, accents and articles, and accepts small typos while pointing them out. React, Vite, Vercel
  3. Chime of Recovery ↗ An indie game developed together with a small team. Java, Game development
  4. Event Locator ↗ A Discord bot that searches for upcoming events near a given city using the Ticketmaster API, leaves out events whose ticket sales have ended, and presents the results as paginated embeds. Python, discord.py, REST APIs
  5. Dutch RVD policies ↗ A collection of responsible vulnerability disclosure policies from 90 Dutch companies, together with a calibration set and the prompts used to analyse them with an LLM. Python, Security research
